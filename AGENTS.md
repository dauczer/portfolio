# Portfolio project instructions

This portfolio intentionally uses a very small visual system.

## References

Before modifying UI, read:
- docs/SOULWIRE_DESIGN.md
- docs/EDITORIAL_LAYOUT.md
- docs/CONTENT.md

## Design rules

- Soulwire is the global visual system.
- Do not reinterpret it into a generic developer portfolio.
- No cards.
- No gradients.
- No shadows.
- No glassmorphism.
- No large marketing hero.
- No traditional navbar.
- No tech-logo wall.
- No decorative pills.
- No arbitrary accent color.

Homepage:
- intro + work index only
- reproduce the measured Soulwire typography, spacing, opacity hierarchy and hover underline behavior
- no intro/typewriter animation

Internal pages:
- same Soulwire colors and Roboto Mono typography
- use the editorial layout rules from EDITORIAL_LAYOUT.md
- normal document scroll
- no decorative animation

## Implementation

- Keep dependencies minimal.
- Prefer simple CSS over UI libraries.
- Centralize project metadata.
- English/French content must be easy to maintain.
- Do not fabricate project details or copy.
- Do not add sections or features unless requested.
